## 规则部件

- **图9 卖**：`aux_edge` 原卖点，即图9 第一次近上轨且辅助卖像，或带内拉伸 B。

## 回落卖出后加冷却：不采用

测过两种冷却，只在回落卖出之后生效，按图9 / 图8 卖出后不受影响：

- **等 N 天**：回落卖出后 N 个交易日内不买，N = 5、10、20。
- **等离开下轨**：回落卖出后，图9 带内位置先回到 20% / 30% / 50% 以上，才允许再买。

回落 15% 和 12% 两档，各种冷却都让 4–6 只变差，只有 1–3 只变好。各标的最优规则加冷却也一样：

**为什么伤收益**：回落卖出后马上再买，常常正好买在急跌的底部。

- 酒 2020-03-17 回落卖出，2020-03-18 再买，这一笔 +166.5%。
- 红利 2020-03-16 回落卖出，2020-03-18 用 B1 买回，这一笔 +16.2%。
- 纳指回落卖出后 8 个自然日内再买 11 次，8 次赚钱，其中 2020-03-17 +24.3%、2023-10-27 +33.6%、2025-04-08 +46.7%、2026-03-30 +31.4%。

**恒生医药**确实有反复被震出去的问题，等 5 天后从 −29.0% / −33.7% 改善到 −22.0% / −27.1%，但只挡掉了 2022-03-09 那笔（−8.9%）。2022-01-26（−15.1%）和 2024-01-22（−11.9%）两笔回落亏损还在。它不设回落是 +7.2% / −31.2%，比加冷却好，所以根源是回落卖出本身不适合这类标的。

**结论**：回落卖出后不加冷却，立刻允许再买。高波动或周期型标的（恒生医药、能源化工）靠不用或少用回落卖出解决，不靠冷却。

## 加 EWMA 上下轨：只对通信有用，不进共性规则

上面所有规则用的轨都是因果 P95 轨：带宽取到当天为止 |ln(收盘/路径)| 的 95% 分位，只扩不缩。HTML 图7–图10 上另画了一套 EWMA 轨，λ = 0.94：σ 用到前一天为止残差的指数加权波动，带宽 = 历史 |残差|/σ 的 95% 分位 × 当天 σ。它的带宽会随最近波动收放，也只用当天以前的数据。

测法：把图9（也测了图8、图10）的上下轨换成 EWMA 轨，再重算近轨、带内位置、拉伸卖、G1 等派生条件，其它不变。另测了两套轨的组合：

- **窄轨**：P95 轨和 EWMA 轨任一触到就算。
- **宽轨**：两套轨都触到才算。

## 图7–图10 EWMA 轨作为新增因素：没有普遍提升

这一节不换轨。原规则（P95 轨）保持不变，把图7、图8、图9、图10 的 EWMA 上下轨做成新条件，一次只叠加一个，看胜率和回撤。胜率按笔算，持有中的那笔按最后一天收盘计。

共 52 个因素，下面的“图k”指图7–图10 中任意一张，每张图都各测一遍：

- **买入过滤**（在原买点上再加条件）：
  - 收盘在图k EWMA 下轨 1% 以内；
  - 图k EWMA 带内位置 ≤ 30% 或 ≤ 50%；
  - 未跌破图k EWMA 下轨；
  - 图k EWMA 带内位置 < 70%；
  - 至少 2 张或 3 张图同时接近 EWMA 下轨。
  
  EWMA 轨为空时放行。纳指 2022-01-13 缺一天收盘，导致图10 路径空了 63 天，不放行会误挡买点。
- **新增买点**（或）：图k EWMA 下轨首次接近且辅助买像；或者 ≥ 2 / ≥ 3 张图同时首次接近 EWMA 下轨。
- **新增卖点**（或）：图k EWMA 上轨首次接近且辅助卖像；或者收盘 ≥ 图k EWMA 上轨。G1 后照样不卖。
- **强制卖**：跌破图k EWMA 下轨，或连续 2 天跌破。不受 G1 限制。
- **回落卖加门槛**：回落达到幅度之外，还要跌破图k EWMA 中轨或下轨，才卖。

叠加到各标的专属规则上（基线中位卡玛 0.77），按类别汇总：

| 类别 | 结果 |
| --- | --- |
| 新增买点（6 个） | 每个都让 4–6 只回撤变深，4–7 只卡玛变差 |
| 新增卖点（8 个） | 每个都让 4–6 只卡玛变差，收益被提前卖掉 |
| 强制卖（8 个） | 每个都让 5–7 只卡玛变差，被正常波动震出 |
| 回落卖加门槛（8 个） | 不改变或变差，破下轨类让 5 只回撤变深 |
| 接近 EWMA 下轨 / 多图共振才买 | 胜率 3–4 只升，回撤 3–5 只变浅，但卡玛 3–5 只变差，好买点被挡掉 |
| 未跌破 EWMA 下轨才买 | 卡玛 4–5 只变差 |
| EWMA 带内位置门槛 | 大多不起作用，见下 |

叠加到共性规则上（基线中位卡玛 0.62），结果相同：没有一个因素在多数标的上同时提高胜率、减小回撤。

**唯一没伤到任何一只的**：买入时要求图10 EWMA 带内位置 ≤ 30%。

| 标的 | 原规则 | 加图10 EWMA 带内 ≤ 30% |
| --- | --- | --- |
| 纳指 | +801% / −18.0%，胜 58%，26 笔 | +896% / −15.4%，胜 62%，24 笔 |
| 通信 | +497% / −38.5%，胜 80%，5 笔 | +530% / −38.5%，胜 100%，4 笔 |
| 其余 5 只 | — | 完全不变 |

改善只来自 3 笔交易：

- 纳指 2025-04-01 那笔 −8.5% 被挡掉，6 天后的 2025-04-07 买入，赚 +44.6%。
- 纳指 2018-12-19 推迟一天买入。
- 通信 2020-10-30 那笔 −5.1% 被挡掉。

门槛改成 20%–25% 时红利变差，35%–40% 时通信的改善消失。共性规则下，只有黄金后段好一些，纳指、通信基本不变。

**单只能找到的**：能源化工买入时要求图8 EWMA 带内位置 ≤ 30%，结果从 +44% / −15.4%（胜 57%）变成 +59% / −10.0%（胜 80%），门槛 20%–30% 都成立。但它只挡掉了 2021-10-28（−7.5%）和 2026-05-26（−3.7%）两笔，门槛到 35% 就退回 +49% / −15%。

**结论**：EWMA 上下轨作为新增因素，在 7 只上没有带来普遍的胜率或回撤改善，不进共性规则，也不改 `rules7`。

- 新增卖点和强制卖都伤收益，原因和回落卖后加冷却一样：EWMA 带在平稳期收窄，正常波动就会触发。
- 买入过滤能提高部分标的的胜率，但通常是把好买点一起挡掉。
- 有改善的两个（纳指、通信用图10，能源化工用图8）都只靠 2–3 笔交易，只当观察项。

## 注意

- 回落幅度对结果很敏感（黄金 12% 与 15% 差近 100 个百分点）。各标的最优档位有一部分是碰巧，只当大致范围。
- 每只的最优组合都是全样本里挑的，样本内；7 只、每只 2–26 笔，没做样本外。
- 分类可以用年化波动、每年穿图7 路径次数、长期在路径上方的天数占比来近似，但和最优规则的对应只有 7 个样本，还不能当规则。
