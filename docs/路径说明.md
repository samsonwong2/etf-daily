# 图7–图11 路径说明

> **身份：读图定义，不改生产。** 生产买卖仍以 `hold_up`（进上涨买、离上涨卖）为准。本文只解释图7–图11 的公平路径、P95 轨和 EWMA 轨。
>
> 实现：`src/etf_daily/plots/plot_regime_transition_example.py` 的 `trailing_log_trend_price_path`、`erp_path_symmetric_envelope`；EWMA 轨在 `src/etf_daily/lib/fair_path_research.py` 的 `ewma_residual_sigma`、`ewma_scaled_envelope`。买卖 checklist 见 [图7-11公平路径上下轨辅助买卖.md](图7-11公平路径上下轨辅助买卖.md)。

## 1. 图7–图11 是什么

它们是同一根 K 线在 5 个时间尺度下的「趋势—偏离」对照面板。

| 面板 | 回归窗口 |
|---|---|
| 图7 | 2 年 |
| 图8 | 1 年 |
| 图9 | 6 个月 |
| 图10 | 3 个月 |
| 图11 | 1 个月 |

每个面板都是：K 线 + 公平路径（中轨）+ 上轨 / 下轨。窗口越短，路径越贴价格，带宽越窄。某一张图上见过的 ±10.2% 到 ±3.4% 是那张图的残差尺度，不是全池常数。

## 2. 公平路径

对每个交易日 t，只用 `[t−N, t]` 窗口内的收盘价（严格因果），对对数价格做最小二乘：

```text
ln P_j = a_t + b_t · j
path_t = exp(a_t + b_t · j_t)
g_t = exp(252 · b_t) − 1
```

- `trailing_log_trend_price_path`：窗口未满时扩张，满了以后滑动。不把全样本系数回填到历史。
- `g_t` 是这条路径的隐含年化增速，图上的「当日路径年化」。它不是同窗口端点算出来的实现 CAGR。
- 上市初期样本不足 63 根时，退化为端点 CAGR 外推，保证尺子连续。

对数线性趋势是该窗口里的条件漂移。价格相对它的偏离 `ln(P_t / path_t)` 是「价格 vs 自身趋势」的偏离，不是基本面公允价值。用它做均值回归，对应的是过度反应和中长期反转这一类证据，不是 CAPE 或股利贴现模型本身。过度反应见 De Bondt and Thaler (1985)；股票收益的中长期均值回归见 Poterba and Summers (1988)。

## 3. 上下轨（expanding P95）

对数残差 `r_s = ln(close_s / path_s)`。对每个 t，取截至当日的全部历史（expanding，因果）：

```text
δ_t = Quantile(|r_s|, s ≤ t, q = 0.95)
上轨_t = path_t · exp(+δ_t)
下轨_t = path_t · exp(−δ_t)
```

图例里的「+10.2%」是 `exp(δ) − 1`，随标的和日期变。

- 这是残差绝对值的经验 95 分位包络，不假设正态。若残差大致对称，价格落出轨道外的历史频率约 5%（每侧约 2.5%）。用分位代替 ±2σ，对厚尾更稳，和用历史分位做 VaR 是同一类做法。
- `δ_t` 只用 `s ≤ t` 的残差，当天看到的轨道和回测当天看到的一致。
- 轨道在对数空间对称。价格空间里 +10% 和 −10% 不对称。

读法：

- 触下轨：相对该尺度趋势偏便宜。代码里 B1 是图9/图10 触下轨，或图8 折价 ≤ −15%。没有长尺过滤时，这是接飞刀候选，见 [防接飞刀_判断指标速查清单.md](防接飞刀_判断指标速查清单.md)。
- 触上轨：相对该尺度趋势偏贵。S1 用图9/图10 触上轨，只作减仓参考，不是生产卖点。
- 图7 回答长尺度贵不贵，图11 回答近端是否极端。图11 不单独触发买卖。

## 4. 使用时的局限

1. 路径是历史外推。趋势真反转时会跟不上，触下轨可以是接飞刀。B2 要求长尺度 `g > 0` 或路径仍在抬升。
2. expanding 的 `δ_t` 吃进全部历史残差。旧的高波动会把带宽长期撑宽，新环境下信号偏保守。图7–图10 因此另画 EWMA 轨，见下一节。图11 仍只有 expanding P95。
3. P95 是无条件历史分位，不是「明天有 95% 概率留在轨内」。
4. 图例里「沪深300公平 4.3%」是另一套东西：公平年化需求收益，锚定 `src/etf_daily/lib/vol_need_return_board.py` 的 `ANCHOR_ERP_ANN = 0.043`。不要和图7–图11 的价格通道混读。
5. 五个窗口、触轨面板、`deep_gap`、盈亏比和 B1–B5 的组合都有挑选空间。哪一档能用，以因果回测的期望收益为准，不以图形为准。

## 5. 信号分层（金融学上站得住的部分）

`src/etf_daily/lib/fair_path_band_signals.py` 里的层次：

| 层 | 在问什么 |
|---|---|
| B1 触下轨或图8 折价 ≤ −15% | 位置是否极端 |
| B2 长尺度 `g > 0` 或路径上行 | 下跌趋势里否决价值信号 |
| B3 短尺度收复中轨 | 不要只靠左侧 |
| B5 盈亏比 ≥ 2 | 这笔辅助仓的结构是否还值得做 |

多尺度对应不同持有期限，不是五套独立系统。严格因果是这些解释能用在回测里的前提。B2 用趋势否决下跌中的价值信号，对应 Asness, Moskowitz and Pedersen (2013) 的价值与动量。

站不稳的地方：

- A 股宽基上，3–12 个月往往动量强于反转，均值回归更多出现在更长的尺度。图9/图10 正好落在动量占优的频段。触上轨就减，会在单边行情里过早离场。
- 触下轨不是「明天 95% 会反弹」，只是「历史上这么偏的时候大约占 5%」。序列不平稳时，这个 5% 会漂。

所以这套指标适合做过滤和仓位调节。B1 没有 B2 时的 `avoid_falling_knife` 有用。它不适合单独当成机械化买卖系统。正式买卖仍是主图绿三角 / 红三角。

## 6. EWMA 上下轨

图7–图10 各画两套轨：expanding P95（点线）和 EWMA 残差轨（青色上轨 / 粉色下轨）。两套轨共用同一条 OLS 路径，只有包络宽度不同。图11 不画 EWMA。

三步，都在 `ewma_scaled_envelope`：

```text
r_t = ln(close_t / path_t)
σ_t² = λ · σ_{t−1}² + (1 − λ) · r_{t−1}²
z_t = r_t / σ_t
δ*_t = Quantile(|z_s|, s ≤ t, q = 0.95)
w_t = δ*_t · σ_t
上下轨 = path_t · exp(±w_t)
```

`λ = 0.94`（RiskMetrics 日频惯例，半衰期约 11 个交易日），取自 J.P. Morgan RiskMetrics (1996)。`σ_t` 只用 `r_{t−1}` 及更早的残差，当天的偏离不进当天的 σ。先用这条 EWMA 波动把残差标准化，再用 `|z|` 的经验分位还原半宽，是 Barone-Adesi, Giannopoulos and Vosper (1999) 的 filtered historical simulation。

P95 分位回答「偏离在历史上多极端」（形状），EWMA σ 回答「现在处于什么波动环境」（尺度）。相乘之后，通道会随波动聚集伸缩。

| | expanding P95 | EWMA 残差轨 |
|---|---|---|
| 问题 | 这个偏离在全部历史上多极端？ | 相对当前波动，多极端？ |
| 宽度 | 旧风暴会长期抬高 δ | 风暴期放宽，平静期收窄 |
| 触轨 | 历史上大约 5% 的时间这么偏 | 按现在的波动尺度，大约 5% 的时间这么偏 |
| 用途 | 长期位置、跨 regime 对照 | 当下是否极端 |

两轨分歧是 regime 诊断：P95 远宽于 EWMA，说明旧高波动还留在 expanding 带宽里，当前波动已经下来，EWMA 更跟得上现在；EWMA 接近甚至宽于 P95，说明当前波动超过历史常态，触 EWMA 轨的「极端」被低估，要更谨慎。

沪深300 上曾经对过图9 半宽：expanding 轨在 2015–2024 约 14.5%、2025 年后约 12.3%；EWMA 轨同期约 7.5% 和 6.5%。那是一只宽基上的对照，不是全池带宽。

EWMA 本身的限制：

1. 它是没有均值回归项的 IGARCH。冲击指数衰减，但不回到一条长期方差。`λ = 0.94` 是惯例，不是这批 ETF 上估出来的。
2. `|z|` 的 P95 仍是 expanding。厚尾程度如果自己在变，惯性从「尺度」挪到「形状」。
3. EWMA 轨更窄，触轨更多。B1 的「5%」从无条件变成条件。B1/S1 改不改用 EWMA 轨，要用前向收益对照，不能看图决定。银行、煤炭的图9 研究档用了 EWMA，规则在 [图9买卖规则融合总表.md](图9买卖规则融合总表.md)，仍然不是生产 `hold_up`。
