# 图7–11 公平路径 / 上下轨辅助买卖判断

> **身份：读图对照，不改生产。** 生产买卖仍以 `hold_up`（进 `up` 买 / 离 `up` 卖）为准；图7–11 与 ED/RU 同为 HTML 诊断层。  
> 算法在 `src/etf_daily/plots/plot_regime_transition_example.py`：前复权收盘价、`trailing_log_trend_price_path` + `erp_path_symmetric_envelope`（因果 P95）。路径定义见 [路径说明.md](路径说明.md)。

## 0. 一句话

| 层级 | 能否单独下单 | 说明 |
|---|---|---|
| **生产** | 否 | 只有绿三角「进入上涨态」= BUY；红三角「离上涨态」= SELL |
| **辅助** | 是 | 多尺度 path / 上下轨 / `g` → 抄底观察、减仓、R:R 量化；需 checklist 打分 |

## 1. 图上三个量怎么读

| 量 | 含义 | 常见误读 |
|---|---|---|
| **公平路径** `path[t]` | 该窗口滚动 log OLS 在 t 的高度（**红虚线** y） | ≠ 公允价值保证 |
| **路径年化 `g[t]`** | 同窗口斜率年化 `exp(b·252)−1`（悬停「当日路径年化」） | ≠ 过去两年实现 CAGR |
| **实现年化 CAGR** | 同窗口端点 `(P_T/P_0)^(252/n)−1`：图例「实现CAGR≈…」=**末日**值；悬停「当日实现年化」=**该日因果**窗端点 | ≠ 历史价格路径；图例末日值不要当成每个历史点的实现年化 |
| **上下轨** | `upper/lower = path · exp(±δ)`，`δ=P95(|ln(c/p)|)` 因果扩展 | ≠ 硬止损；极端日可刺穿 |
| **相对路径因果分位** | 悬停：`|ln(c/path)|` 在历史≤t 的经验分位，path 上为正（`+P72`）、下为负（`-P45`）；与轨同一残差定义 | ≠ 收益分位；`±P95` 约等于贴上/下轨 |

图7–11：**红虚线** = OLS 路径年化 `g`；实现 CAGR 只作图例/悬停数字，与路径 g 本可不同。仅窗口不同（2年 / 1年 / 6个月 / 3个月 / 1个月），**不是五套独立系统**。环境变量 `FAIR_PATH_SHOW_REALIZED_CAGR=0` 可关闭实现 CAGR 数字。

## 2. 每日操作顺序（5 步）

1. **主图**：`regime` + 绿/红三角（生产权威）。
2. **图7–8**：长尺 `g`、path 是否仍抬升 → 是否允许「向路径回归」叙事。
3. **图9–10**：价 vs path / 上下轨 → 深折价 + 止跌，或近上轨减仓。
4. **图11**：只看近端节奏，**不单独触发买卖**。
5. **ED / RU**：ED 降权；RU 支持修复叙事，仍需短尺收复 path 才考虑加仓。

- 把 P95 轨当硬止损（设计上允许刺穿）。
- 用图例期末 `g≈…%` 代替**当日** hover 的 `当日路径年化`。
- 未复权价与 HTML（qfq）混算 path / 轨。

## 7. R:R 快速算（辅助仓）

```
Reward% = 目标价 / 买价 − 1    （目标价 = 对应 fig path，或 (买价+path)/2）
Risk%   = 买价 / 止损价 − 1    （止损价 = 买价 − 1×ATR20，或买日低点 − ε）
R:R     = Reward% / Risk%      （主观抄底希望 ≥ 2～3，再乘置信折扣 0.3～0.6）
```

## 9. 回测结果（20260821 池，OOS≥2025-01-01，研究修订）

> 数据：HTML fig7 抽价（与报告同源）；出场：目标=fig10 path / 止损=−1 ATR / 最长 40 日；信号间隔≥5 日。

### 入场变体（默认 deep_gap=−15%，target=fig10，hold=40）

| 变体 | n_trades | WinRate | mean_ret | TargetHit | 说明 |
|---|---:|---:|---:|---:|---|
| baseline_touch | 251 | 30.3% | 0.33% | 23.9% | 仅触轨+B2，**偏弱** |

B123 附加指标：FwdHit@20d **63.2%**；LeadRate（20 日内出现生产 BUY）**21.9%**。

### 规则调整建议（回测修订）

1. **主买点用 B123**，不要单独用触轨（baseline_touch）。
2. **B3 保留**；消融里 `reclaim_from_lo`（昨触下轨、今收回）mean_ret 更高但 n_trades 少，可作「高质量小样本」备选。
3. **deep_gap**：默认 −15%；要更多信号试 −10%，要更深折价试 −20%。
4. **B1 触轨**：可只用 fig10（略升 mean_ret，减噪声）。
5. **B5/B4**：默认不加；B1235 与 B123 接近，B12345 样本太少。
6. **出场**：目标 fig10 path + hold 40d；fig8/fig9 目标 TargetHit 低但 mean_ret 有时更高（路径更远）。
7. **S1 减仓**：up 态近上轨后 5/10 日下跌比例仅 ~46%，**减仓信号不强**，宜作主观参考。
