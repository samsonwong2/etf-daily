## 判断参数

轨来自 `ewma_scaled_envelope`（λ=0.94，expanding P95(|z|)×当前 σ，严格因果）。路径仍是图9 的 6 个月 OLS。

| 符号 | 定义 |
|---|---|
| 近下 | `收盘 ≤ EWMA 下轨 × 1.015` |
| 近上 | `收盘 ≥ EWMA 上轨 × 0.985` |
| 硬触上 | `收盘 ≥ EWMA 上轨` |
| 距上 `dist_hi` | `收盘 / EWMA上轨 − 1` |
| 上跳沿 / 落下沿 | 昨日假今日真 / 昨日真今日假 |

辅助买像：`收盘 < MA20` ∧ `MA5 < MA20` ∧ `gap5 ≤ 0` ∧ `gap20 ≤ 0` ∧ **图10 未触上轨**。卖日**不要求**辅助卖像。

| 参数 | 选定 |
|---|---|
| lam | **0.94** |
| near_pct | **0.015** |
| 买 | L0：EWMA 近下上跳沿 ∧ 辅助买 |
| 卖 | 触上离开：本轮近上曾硬触上轨，落下沿且 `dist_hi ≤ −3%` |
| 带内拉伸 / 失败 C / locmin / G0 | **关** |
