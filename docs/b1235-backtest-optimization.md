# B1235 回测与优化建议

数据是本机 `/home/huangtuo/temp/plotly_outputs/20260929_from_listing` 的 regime HTML，由 `etf-daily b1235-backtest` 跑出。样本内 2014–2021（22 只），样本外 2022-01-01 至 2026-09-29（54 只）。入场为信号次日开盘。超额 = 20 日收益减同日全池等权均值，t 值按信号日聚合。

## 一句话结论

**在你的 listing 池上，现行 B1235 样本内没有超额，样本外有一点，但不够稳，也不适合当独立策略。**

|                   | 信号 | 20日均收益 | 20日胜率 | 20日超额 (t)       | 等权篮子年化 / 最大回撤 / Sharpe |
| ----------------- | ---- | ---------- | -------- | ------------------ | -------------------------------- |
| 全池，样本内      | 1729 | 0.87%      | 55.9%    | 0                  | 10.3% / −32.3% / 0.66            |
| **B1235，样本内** | 89   | 0.66%      | 51.7%    | **−0.51% (−0.49)** | −1.4% / −29.9% / 0.00            |
| 全池，样本外      | 4587 | 0.80%      | 52.2%    | 0                  | 7.0% / −12.5% / 0.56             |
| **B1235，样本外** | 260  | 1.69%      | 58.9%    | **+0.74% (1.27)**  | 5.1% / −30.7% / 0.34             |

样本外 20 日收益高于全池（1.69% 对 0.80%），超额 +0.74%，t 只有 1.27。做成 20 日等权篮子后，年化 5.1% 低于持有全池的 7.0%，最大回撤 −31% 远深于全池的 −12.5%。约 60% 的模拟交易打到 1×ATR 止损。

四个条件里，**只有 B1 在干活**。去掉 B1，样本外超额从 +0.74% 掉到 −0.12%。B2、B5 去掉后样本外几乎不变。B3 里「站上图10路径」这一支样本外超额 **−1.47%（t=−1.72）**，是唯一明显亏钱的分支。

**建议只改一条：B3 去掉「站上图10」，保留「站上图11」或「图10昨触今收回」。** 样本外超额升到 +1.03%（t=1.78），篮子年化升到 6.6%，仍低于持有全池，回撤仍约 −33%。

先前用腾讯数据时建议加的「上市≥1年」，在这份池上**没有增量**：超额与只改 B3 相同（+1.03%），篮子年化反而降到 5.2%。这条不采用。

- **B2** 去掉只少约 8% 的样本外信号，超额还略好。两个「路径 20 日抬升」子项样本内为负。可以留着，也可以收成「图7或图8 g>0」，不必加严。
- **B3** 整体有用（去掉后样本外超额降到 +0.43%），但「仅站上图10」样本内 −1.08%（25 笔）、样本外 −1.47%（64 笔，t=−1.72）。「仅站上图11」样本外 +0.94%（t=1.59），「仅图10昨触今收回」样本外 +1.25%（t=1.13）。
- **B5** 的 min_rr 从 0.5 调到 2.5，样本外超额都在 +0.69% 到 +0.76%。调到 4 样本外升到 +1.06%，样本内掉到 −0.84%，不改。止损从 1×ATR 放到 2×ATR 时，样本外模拟均收益从 +1.07% 升到 +1.68%、止损占比从 60% 降到 49%，但样本内模拟均收益从 +0.23% 变成 −0.24%。这同时改了入选名单，不能当成纯出场改进。

## 怎么用

1. 筛选时用 `etf-daily b1235 --b3-mode fig11_or_reclaim`。默认规则先不动，这个参数是可选的。
2. 不要加 `--min-listing-years 1`。在这份池上它不提高超额，还减少信号。
3. deep_gap 保持 −15%，min_rr 保持 2。B2 可留可去。
4. 信号当观察清单。不要按信号等权满仓：样本外篮子回撤约 −31%，持有全池只有 −12.5%。
5. 若真按信号交易，1×ATR 止损太紧（约六成被打掉）。放宽到 2×ATR 只在样本外的模拟里更好，样本内模拟更差，先别写进规则。
