## 1. 共同骨架

默认下轨/上轨是图9 **P95**。银行 SH512700、煤炭 SH515220 买用同一套 L0 接到图9 **EWMA** 轨；卖用触上离开，不是 S0。

| 项 | 定义 |
|---|---|
| 近下 / 近上 | `收盘 ≤ 下轨×(1+near)` / `收盘 ≥ 上轨×(1−near)`；P95 档默认 near=1%；银行 / 煤炭 EWMA 档 near=1.5% |
| 触下 / 触上 | `收盘 ≤ 下轨` / `收盘 ≥ 上轨` |
| 距上 `dist_hi` | `收盘/上轨 − 1`（负值 = 已离开上轨） |
| 带内分位 `pos` | `(ln收盘 − ln下) / (ln上 − ln下)` |
| 路径年化 `g` | 该尺滚动 log 斜率年化 |
| 上跳沿 | 昨日假、今日真 |
| 辅助买像 | `收盘<MA20` ∧ `MA5<MA20` ∧ `gap5≤0` ∧ `gap20≤0` ∧ **图10 未触上** |
| 辅助卖像 | `收盘>MA20` ∧ `MA5>MA20` ∧ `gap5≥0` ∧ `gap20≥0` |
| 带内拉伸 (B) | 辅助卖 ∧ locmax(10d) ∧ 图9 `pos≥80%` ∧ `g>0` ∧ ¬硬碰上 ∧ `vol5_pct_120d≥0.70` ∧（图7 溢价≥5% 或 图10 `pos≥90%`） |
| 成交 | 只做多；空仓才买、持仓才卖；**信号日收盘确认，次日收盘成交** |

图2 量、图6 净值不进这些规则。

## 6. 怎么用这张表

1. 先过门：G0 → 用 `hold_up`；G1/G2/G3 → 黄金框架。
2. 第一次近下可信 → L0；贴着下轨走 → L1；第一次是试探 → L2/L2′；飞刀多 → 状态日 + 闸 F。
3. 贴上后回中轴快 → S0；会骑出去 → S1/S1′；银行 / 煤炭 EWMA → 硬触上后再离开 3%；到不了上轨 → 失败 C/C′。
4. **不要混档**：通信的骑轨不要套煤炭；黄金切换不要套煤炭；豆粕穿回不要套红利；中概 `g>0` 闸不要拿掉再去买 2026-03。
5. 阈值（4 日 vs 8 日、−3% vs −5%、软买 `pos≤15%`）是单票拟合，换票先对照源文档，不要当全池常数。

单票成交表、不要做的日期、复现命令，仍在旧仓库第 0 节那些文件里，没有迁入。
