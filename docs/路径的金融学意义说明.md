## 有坚实金融学依据的部分

\1. 公平路径 = 可交易的"价值锚"（有意义） 对数线性趋势就是 GBM 框架下的漂移项轨迹，价格相对它的偏离 ln⁡(Pt/patht)\ln(P_t/\text{path}_t)ln(Pt/patht) 在概念上等价于 Shiller CAPE 偏离、股利贴现模型的残差——即"价格 vs 基本面趋势"的 mispricing 度量。用它做均值回归有学术支撑（De Bondt & Thaler 的过度反应、Poterba & Summers 的均值回归证据）。

\2. P95 包络比 Bollinger 更稳健（有意义） 用残差绝对值的经验 95 分位代替 ±2σ，不假设正态、对厚尾稳健——这本质是一个非参数的经验置信通道，和用历史分位做 VaR 是同一逻辑。A 股收益厚尾明显，这个选择是对的。

\3. 信号结构暗合"价值 + 趋势 + 择时"三因子框架（设计合理）

- B1（触下轨/深度折价 ≤ −15%）= 价值/位置条件；
- B2（长尺度 g>0g>0g>0 或路径上行）= 趋势过滤——这正是文档里"防接飞刀"的机制，学术上对应 value 与 momentum 结合（Asness 的 *Value and Momentum Everywhere*），价值信号在下跌趋势中必须被趋势条件否决；
- B3（短期收复中轨）= 择时确认，避免左侧过早进场；
- B5（RR ≥ 2 盈亏比）= 期望值为正的结构化约束。

单独看每一层都有金融学出处，组合起来是一个逻辑自洽的 checklist，而不是拍脑袋的规则堆叠。

\4. 多尺度分工有投资者期限结构的含义 图7（2年）回答"长期贵不贵"，图11（1个月）回答"短期情绪是否极端"——这对应市场上不同持有期限资金的定价分层，窗口越短路径越贴价格、带宽越窄（±10.2% → ±3.4%）是残差尺度的自然性质，符合直觉。

\5. 严格因果是"有实盘意义"的前提（最重要的加分项） 路径用 trailing 窗口、带宽用 expanding 历史，当天看到的就是回测看到的样子。没有这一条，前面所有金融学解释都不成立。

## 金融学上的存疑与风险

\1. 均值回归假设在 A 股宽基上并不稳 学术证据里，指数层面 3–12 月尺度 momentum 往往强于反转，长期（3–5 年）才有均值回归。图9/图10（6 个月/3 个月窗口）恰好落在"动量占优"的频段——S1 触上轨就减仓，在 2017 白马、2020 核心资产这类单边趋势行情里会持续过早离场，机会成本很高。

\2. expanding 带宽的 regime 惯性是真问题 文档第 54 行自己也承认了：2007/2015 式高波动旧 regime 会让 δt\delta_tδt 长期偏宽，新 regime 下信号系统性偏保守。改进方向是滚动窗口（如 3–5 年 rolling P95）或对残差做 EWMA/GARCH 标准化，让通道自适应波动聚集。

**（2026-09-09 更新：该改进已落地——图7–图10 现在叠加了 EWMA 残差轨，见下文"EWMA 上下轨的金融学意义"一节。）**

\3. P95 是无条件分位，不是预测区间 文档第 55 行这点说得对，但使用时容易忘：触下轨不是"明天 95% 概率反弹"，只是"历史上这么偏的概率约 5%"。在非平稳序列上，这个 5% 本身会漂移。

\4. 多尺度 + 多参数存在数据挖掘空间 5 个窗口、touch_panels、deep_gap、min_rr、B 的 5 种组合模式（baseline_touch/B12/B123/B1235/B12345）——自由度不小。"哪个组合有效"如果是从历史里挑出来的，就有过拟合嫌疑。好在代码里 `simulate_trades` 和 `fwd_ret_{n}d` 的前向收益统计就是用来验证这个的，结论应以这些因果回测的期望收益为准，而不是图形本身。

## EWMA 上下轨的金融学意义（2026-09-09 新增）

图7（2年）、图8（1年）、图9（6个月）、图10（3个月）现在各画两套轨：原来的因果 expanding P95 轨（点线）+ 新增的 EWMA 残差轨（青色上轨 / 粉色下轨，dashdot 线）。图11（1个月）仍只画 expanding P95。两套轨共享同一条 OLS 公平路径，只有包络宽度不同。

### 构造：标准化残差的非参数分位 × 当前 EWMA 波动

实现见 `decision_pack/src/fair_path_research.py` 的 `ewma_residual_sigma` 与 `ewma_scaled_envelope`，分三步：

1. **残差不变**：仍是 rt=ln⁡(closet/patht)r_t = \ln(\text{close}_t / \text{path}_t)rt=ln(closet/patht)，即价格相对公平路径的对数偏离；
2. **EWMA 波动率**：σt2=λσt−12+(1−λ)rt−12\sigma_t^2 = \lambda\sigma_{t-1}^2 + (1-\lambda)r_{t-1}^2σt2=λσt−12+(1−λ)rt−12，λ = 0.94（RiskMetrics 日频标准参数）。严格因果——σt\sigma_tσt 只用 rt−1r_{t-1}rt−1 及更早的残差，当天的偏离当天不进 σ；
3. **标准化后取分位再乘回来**：zt=rt/σtz_t = r_t / \sigma_tzt=rt/σt，对 ∣z∣|z|∣z∣ 取因果 expanding P95 得 δt∗\delta_t^*δt∗，最终半宽 wt=δt∗⋅σtw_t = \delta_t^* \cdot \sigma_twt=δt∗⋅σt，上下轨 = path⋅e±w\text{path} \cdot e^{\pm w}path⋅e±w。

一句话：**P95 分位回答"偏离在历史上多极端"（形状），EWMA σ 回答"现在处于什么波动环境"（尺度），两者相乘得到一条随波动聚集自适应伸缩的通道。**

### 对应的学术概念

- **RiskMetrics EWMA 波动率**（J.P. Morgan, 1996）：λ = 0.94 是日频数据的行业标准默认值，半衰期约 11 个交易日——一场已结束的风暴对带宽的影响在几周内衰减到可忽略，而不是像 expanding 窗口那样残留数年。这直接修复了上一节第 2 条指出的 regime 惯性问题。
- **波动率标准化残差 ≈ IGARCH**：EWMA 方差递推等价于无均值回归项的 GARCH(1,1)（即 IGARCH），是"用条件波动替代无条件波动"的经典做法。
- **Filtered Historical Simulation（FHS）**：先对残差做条件波动标准化、再用标准化残差的经验分位还原区间——这正是 Barone-Adesi 等人的 FHS VaR 框架。所以 EWMA 轨可以理解为"条件版"的非参数通道，expanding P95 轨则是"无条件版"。

### 与 expanding P95 轨的解读差异

| | expanding P95 轨 | EWMA 残差轨 |
|---|---|---|
| 回答的问题 | 这个偏离在**全部历史**上多极端？ | 这个偏离相对**当前波动 regime** 多极端？ |
| 宽度行为 | 只增不减（旧风暴永久抬高 δ） | 随 σ 自适应：风暴期放宽、平静期收窄 |
| 触轨语义 | "历史上约 5% 的时间这么偏" | "按现在的波动尺度衡量，约 5% 的时间这么偏" |
| 适用场景 | 长期位置感、跨 regime 可比 | 当下可交易性、及时性 |

沪深300 上的实测对比（`temp/sh510300_expanding_vs_ewma/fig9_width.csv`）：图9 单侧半宽中位数，expanding 轨 2015–2024 约 14.5%、2025 年后约 12.3%；EWMA 轨同期只有约 7.5% 和 6.5%——**平静 regime 下 EWMA 通道约为旧通道一半宽**，触轨更早、更频繁；风暴过后它也会自动收紧，不会长期"张着口"。

### 双轨并列本身的信息量

两轨的分歧就是 regime 诊断：

- **P95 轨远宽于 EWMA 轨** → 旧高波动 regime 的残留，当前实际波动已降温，expanding 信号会系统性偏保守（此时 EWMA 轨更可信）；
- **EWMA 轨接近甚至宽于 P95 轨** → 当前波动飙升、超过历史常态，市场处于聚集/极端 regime，触 EWMA 轨的"极端程度"被低估，应更谨慎。

### 新增的风险点

1. **EWMA 是 IGARCH，无均值回归**：波动冲击的影响指数衰减但永不回到长期方差，且 λ = 0.94 是惯例参数而非样本内优化所得（好处是少一个过拟合自由度）。
2. **标准化分位仍是 expanding**：ztz_tzt 的分布若漂移（比如厚尾程度本身变化），δt∗\delta_t^*δt∗ 同样有惯性，只是惯性从"尺度"挪到了"形状"。
3. **触轨稀有性语义变了**：EWMA 轨更窄 → 触轨次数更多，B1"5% 极端"的含义从无条件变成条件。B1/S1 是否应该改用 EWMA 轨判定，不能凭图形直觉，要用前向收益回测对比——`temp/eval_sh510300_expanding_vs_ewma.py` 的事件研究和 `simulate_trades` 对比（expanding vs ewma 两套轨、同一 OLS 路径）就是为此准备的，结论应以其实际胜率和期望收益为准。

## 结论

有明确的金融学意义：它是一个"对数趋势锚 + 非参数极值通道 + 趋势过滤 + 盈亏比约束"的均值回归框架，每一层都有对应的学术概念，且因果构造保证了可验证性。EWMA 残差轨的加入（图7–图10）把"非参数极值通道"从无条件版升级为"无条件 + 条件"双尺度对照，直接回应了上文"存疑与风险"第 2 条的 regime 惯性批评，框架的自洽性因此更强。

但它的金融学有效性有条件：依赖残差序列的平稳性和该资产的均值回归强度，而这两点恰恰是时变的。图形回答的是"位置离不离谱"，回答不了"这次会不会回归"——后者只能靠代码里已有的前向收益回测来下结论。所以这套指标适合作为择时过滤器/仓位调节器（尤其 B1 无 B2 时的 `avoid_falling_knife` 判定很有价值），不适合单独作为机械化买卖系统。
