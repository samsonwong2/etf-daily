# 防接飞刀判断指标速查清单

> **身份：读图对照，不改生产。** 生产买卖仍以 `hold_up` 为准。这里的 B1 是图7–图11 的辅助触发，不是绿三角。
>
> 来源：黄金下跌识别、能源化工验证两篇单票稿的组合用法，那两篇留在旧仓库 `etf_strategy_clean/documents/`，没有迁入。  
> 指标都是 `compute_multi_scale_frame` + `enrich_frame_for_checklist`（`src/etf_daily/lib/fair_path_band_signals.py`）的现成列。路径定义见 [路径说明.md](路径说明.md)。

## 总原则

先判断这轮下跌是"暴涨后的急转"还是"慢慢滚下来的"：前者用快信号（fig11_g、连续破位），后者用稳信号（fig10+fig9 双空）加锚止跌；任何情况下 B1 都不能裸奔；跌完没跌完，按"收复路径 → g 收敛 → g 转正"三步走，不抢跑。

## 第一步：判断下跌形态（快 vs 慢）

**指标：最近 40~60 个交易日的涨幅**（用 `px` 列直接算）

| 条件 | 形态 | 依据 |
|---|---|---|
| 近 1~2 个月涨幅 ≥ +20%（如 D 段 40 天 +40%、A 段 3.5 个月 +80%） | **暴涨后急转** | 3~6 个月窗口被污染，fig10_g/fig9_g 不可信 |
| 无近期暴涨，顶部是横盘/缓涨滚出来的（如黄金、C 段） | **慢速滚动顶** | 窗口干净，稳信号可用 |

辅助确认：看 fig10_g 的绝对值——如果价格已经开始跌、fig10_g 还在 +100% 以上（D 段 04-21 时 +365%），说明窗口被暴涨顶住了，属于快形态。

## 第二步：刀锋过滤（B1 触发时必须叠加）

**B1 触发条件**（生产口径）：`fig9_touch_lo` 或 `fig10_touch_lo` 为 True，或 `fig8_gap ≤ −15%`。

触发后查过滤器：

| 形态 | 拦截条件（任一成立即判接飞刀，不买） | 对应列 |
|---|---|---|
| 快形态 | `fig11_g ≤ 0`，或**连续 10 日** `px < fig10_path` | `fig11_g`、`px` vs `fig10_path` |
| 慢形态 | `fig10_g ≤ 0` 且 `fig9_g ≤ 0` | `fig10_g`、`fig9_g` |

**不要用** `fig7_g` / `fig8_g`（生产 B2 用的）做这道过滤——四段下跌实测它们合计只拦了 2 天。

## 第三步：慢阴跌加一道锚止跌（规则③）

| 指标 | 条件 | 含义 |
|---|---|---|
| `fig9_path_rising`（fig9 路径 20 日前对比） | 为 False（路径还在下坡）→ 不买 | 锚在下沉，"便宜"是幻觉 |
| 辅助：`px < fig10_path` 的持续天数 | 连续超过 20~30 天 → 确认慢阴跌 regime | C 段实测 224/397 天在路径下 |

## 第四步：解除警报三步走（不抢跑）

| 步骤 | 指标 | 确认条件 | 语义 | 实例 |
|---|---|---|---|---|
| ① 止跌 | `px ≥ fig10_path` | 收盘站回 3 个月路径上方 | 跌势暂停，可能反复 | D 段 07-13 |
| ② 动能耗尽 | `fig10_g` 连续收敛 | 从深负值持续收窄（如 −50% → −10%），不要求单日 | 下跌动能在衰竭 | D 段 8 月全月 |
| ③ 趋势结束 | `fig10_g > 0` | 3 个月年化斜率转正 | 下跌趋势正式结束，可考虑进场 | D 段 09-01（+5.0%） |

注意区分：fig9_g 转正不是必要条件——D 段到 09-10 fig9_g 仍是 −20%，属于"修复中"，仓位上留有余地即可。

## 汇总决策表

```
价格触发 B1（fig9/fig10 触下轨 或 fig8_gap ≤ −15%）
        │
        ▼
近 1~2 个月涨过 ≥ +20%？
   ├─ 是（快形态）→ fig11_g ≤ 0 或 连续10日 px < fig10_path？→ 是：不买
   └─ 否（慢形态）→ fig10_g ≤ 0 且 fig9_g ≤ 0？→ 是：不买
                   └─ fig9_path_rising = False（锚在下沉）？→ 是：不买
        │ 全部通过
        ▼
   可以小仓试探，且必须等 B3（收复 fig10/fig11 路径）确认再加仓
        │
        ▼
持有期间监控退出/加仓：收复 fig10 路径 → fig10_g 收敛 → fig10_g 转正
```

## 涉及的全部数据列

`px`、`fig7_g` ~ `fig11_g`、`fig9_path`、`fig10_path`、`fig9_touch_lo`、`fig10_touch_lo`、`fig8_gap`、`fig9_path_rising`。

均为 `compute_multi_scale_frame` + `enrich_frame_for_checklist` 的现成输出，不需要新增指标。
